# 介面改版說明

本次改版以公開網站的「資訊層級清楚、卡片式區塊、行動裝置友善」作為一般設計方向，所有樣式均由本專案自行撰寫於 `modern-ui.css`。

- 未複製第三方網站的 HTML、CSS、JavaScript、圖片、圖示、文案或資料表。
- `index.html` 原有的校科資料與成績判斷邏輯均維持不變。
- 歷年錄取資料、適用年度與招生規則應由網站維護者依公開且可驗證的來源自行更新；選填時以高雄區免試入學委員會及各校正式公告為準。
- 新樣式以 `<link href="modern-ui.css?v=20260919">` 載入；如需回復舊視覺，可移除該行，不影響資料與功能。
